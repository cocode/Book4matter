# Quick start

- **book4matter web.** Add your manuscript, enter your book details, and choose an output format. [Open the web app](https://app.book4matter.com/)
- **book4matter cmd with Docker.** Run the published image with your book folder mounted. [Use Docker](https://book4matter.com/examples/docs/book4matter.html#option-1-the-docker-hub-image)
- **book4matter cmd from source.** Install the dependencies and build with `python3 -m bf`. [Install from source](https://book4matter.com/examples/docs/book4matter.html#option-2-install-directly-without-docker)

To adapt a sample project, see [Start a book from an example](https://book4matter.com/examples/docs/book4matter.html#project-quickstart).
The same manual covers [Markdown](https://book4matter.com/examples/docs/book4matter.html#markdown), [tables of contents](https://book4matter.com/examples/docs/book4matter.html#contents-settings),
and [indexes](https://book4matter.com/examples/docs/book4matter.html#an-alphabetical-index-of-terms) for both web and cmd.
