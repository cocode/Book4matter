# Book4matter

**Write in Markdown. Publish everywhere.** Book4matter turns a folder of plain
Markdown into a print-ready paperback interior, a shareable PDF with live links,
an EPUB, and a website — all from one source, all styled from one place.

It was built to take a manuscript to Amazon KDP without fighting a word
processor: real book typography, correct trim size and gutter margins, and
output you can hand straight to a printer or a reader.

> This very page is a Book4matter site. It was written in Markdown in
> `web/chapters/`, and rendered to HTML by the same tool it describes.

## Why it exists

Word processors tangle *what you wrote* with *how it looks*, and every export
format drifts a little further from the last. Book4matter keeps them separate:

- Your **manuscript** is Markdown you can read, diff, and version in git.
- The **metadata** (title, author, rights) lives in one small YAML file.
- The **style** (trim, margins, fonts) lives in another.

Point ten books at one style file and restyle them all from a single edit. The
manuscript never changes.
